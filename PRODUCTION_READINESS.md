# Governed academy media release
The production-oriented path is `/api/governed-media-releases`. Tenant membership, Bearer auth, `X-Tenant-Id`, and `Idempotency-Key` are mandatory. Releases preserve source, asset, timeline, render, rights, consent, accessibility, moderation, approval, publish/export, and usage evidence as immutable digests and versions.
Apply `backend/migrations/001_governed_media_release.sql` only through a reviewed deployment migrator. Media/model, rights-library, storage/CDN, transcription/translation, publishing, and accounting adapters remain unconfigured until credentials, contracts, rights review, retry/replay tests, and usage reconciliation exist. Generated and provider routes are quarantined in production.
Deterministic checks never publish. Real audio/video rendering, timing/layout fidelity, accessibility, multilingual output, rights, safeguarding, watermark/disclosure, and brand acceptance require approved fixtures and qualified reviewers.
Configure secrets from `.env.example`; keep bootstrap/demo/provider flags false. Run `node --test backend/src/governance/*.test.cjs` and `bash -n start.sh`. Startup performs no installation, database creation, migration, seeding, or port termination.
